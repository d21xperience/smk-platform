# SIAKAD Guru

Aplikasi SIAKAD untuk Guru - SMK Platform

## Tech Stack

- **Framework:** Quasar Framework + Vue 3
- **State Management:** Pinia
- **Language:** JavaScript (ES6+)
- **HTTP Client:** Axios

## Development

```bash
# Install dependencies
yarn install

# Start dev server
yarn dev

# Build for production
yarn build

# Lint code
yarn lint

# Format code
yarn format
```
